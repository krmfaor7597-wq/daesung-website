컴퓨터 네트워크

컴퓨터네트워크는 컴퓨터와 컴퓨터가 데이터를 주고받는 원리를 배우는 분야입니다. 우리가 웹사이트에 접속할 때도 IP 주소, DNS, TCP/IP, HTTP 같은 기술들이 함께 동작합니다.

TCP/IP

인터넷 통신의 기본 구조이며, 데이터를 목적지까지 전달하기 위한 핵심 프로토콜입니다.

DNS

사람이 기억하기 쉬운 도메인 이름을 실제 IP 주소로 변환하는 시스템입니다.

HTTP/HTTPS

웹브라우저와 웹서버가 정보를 주고받는 방식이며, HTTPS는 보안 연결을 제공합니다.

IP 주소와 포트

IP 주소는 장치를 구분하고, 포트는 장치 안에서 실행되는 프로그램을 구분합니다.

Wireshark

실제 네트워크 패킷을 캡처하고 분석하여 통신 과정을 눈으로 확인할 수 있습니다.

GitHub Pages

HTML 파일을 GitHub 저장소에 올려 정적 웹사이트로 배포할 수 있는 서비스입니다.

전기공학 소개

전기공학은 전기에너지의 생산, 변환, 제어, 전달, 활용을 다루는 학문입니다. 발전소에서 만들어진 전기가 가정과 산업현장으로 전달되는 과정부터, 전자회로와 제어 시스템까지 폭넓은 분야를 포함합니다.

회로 이론

전압, 전류, 저항, 전력의 관계를 이해하고 전기 시스템의 기본 원리를 학습합니다.

제어공학

시스템이 원하는 동작을 하도록 입력과 출력을 조절하는 방법을 배웁니다.

전력 시스템

전기를 생산하고 송전, 배전하여 사용하는 전체적인 흐름을 이해합니다.
