컴퓨터 네트워크 핵심 개념

웹사이트 접속은 단순히 주소를 입력하는 과정이 아니라, 도메인 이름 해석, 서버 연결, HTTP 요청과 응답이 순서대로 이어지는 네트워크 과정.

IP Address

네트워크에서 서버와 장치를 구분하는 주소.

DNS

도메인 이름을 실제 서버 IP 주소로 변환하는 시스템.

HTTP / HTTPS

브라우저와 웹서버 사이의 요청 및 응답 규칙.

GitHub Pages

HTML, CSS, JavaScript 파일을 정적 웹사이트로 공개하는 서비스.

Domain

사람이 기억하기 쉬운 웹사이트 주소.

DNS Record

회로 이론

전력 시스템

전자회로

임베디드 시스템
