컴퓨터 네트워크

컴퓨터네트워크는 컴퓨터와 서버가 데이터를 주고받는 과정을 이해하는 분야입니다. 웹사이트 접속 과정에는 IP 주소, DNS, TCP/IP, HTTP, HTTPS 등 다양한 기술이 함께 동작합니다.

TCP/IP

인터넷에서 데이터를 주고받기 위한 기본 통신 구조를 이해합니다.

DNS

도메인 이름을 실제 서버의 IP 주소로 변환하는 과정을 학습합니다.

HTTP/HTTPS

브라우저와 웹서버가 요청과 응답을 주고받는 방식을 이해합니다.

IP 주소와 포트

네트워크 장치와 프로그램을 구분하는 주소 체계를 정리합니다.

Wireshark

실제 패킷을 캡처하고 분석하며 네트워크 흐름을 확인합니다.

GitHub Pages

정적 HTML 파일을 인터넷에 공개하는 웹 배포 과정을 경험합니다.

전기공학 소개

전기공학은 전기에너지의 발생, 전달, 변환, 제어, 활용을 다루는 학문입니다. 회로, 제어, 전력, 전자, 임베디드 시스템 등 다양한 분야와 연결되어 있습니다.

회로 이론

전압, 전류, 저항, 전력의 관계를 바탕으로 전기 시스템의 기본 원리를 학습합니다.

제어공학

시스템이 원하는 동작을 하도록 입력과 출력을 조절하는 방법을 배웁니다.

전력 시스템

발전, 송전, 배전, 부하까지 전기에너지의 흐름을 이해합니다.

전자회로

다이오드, 트랜지스터, 센서 등 전자 부품을 활용한 회로 구성을 학습합니다.

임베디드 시스템

아두이노와 센서 등을 이용해 실제로 동작하는 시스템을 구현합니다.

융합적 사고

전기공학 지식과 소프트웨어, 네트워크 기술을 함께 활용하는 능력을 기릅니다.

학습 내용 정리

이번 웹사이트는 단순히 HTML을 작성하는 것에서 끝나는 것이 아니라, 웹페이지가 인터넷에 공개되는 과정을 직접 경험하는 데 의미가 있습니다.

HTML

웹페이지의 제목, 문단, 메뉴, 섹션 등 기본 구조를 작성했습니다.

CSS

색상, 레이아웃, 카드 디자인, 반응형 화면, 애니메이션 효과를 적용했습니다.

JavaScript

메뉴 클릭 시 원하는 위치로 부드럽게 이동하는 기능을 구현했습니다.

Repository

GitHub 저장소를 생성하고 index.html 파일을 관리했습니다.

Pages

GitHub Pages 기능을 사용해 작성한 파일을 실제 웹사이트로 배포했습니다.

Domain

도메인 이름과 웹사이트 주소가 연결되는 개념을 이해했습니다.

미니프로젝트 제작 과정

아래 과정은 자기소개 홈페이지를 제작하고 인터넷에 공개하기까지의 주요 단계입니다.

1단계 GitHub 계정 로그인 및 저장소 생성
2단계 index.html 파일 생성 및 기본 코드 작성
3단계 자기소개, 전공 소개, 네트워크 내용 구성
4단계 CSS를 이용한 디자인 및 반응형 화면 제작
5단계 GitHub Pages 설정으로 웹사이트 배포
6단계 최종 접속 확인 및 제출용 홈페이지 완성

마무리

이번 미니프로젝트를 통해 웹페이지 제작, GitHub 저장소 관리, GitHub Pages 배포 과정을 직접 경험했습니다. 또한 컴퓨터네트워크에서 배우는 웹 접속, 서버, 도메인, HTTP 개념이 실제 홈페이지 제작 과정과 연결된다는 점을 확인할 수 있었습니다.
