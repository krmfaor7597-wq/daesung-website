자기소개

경남대학교 전기공학과 김대성. 전기공학의 기본 이론과 웹 서비스가 동작하는 네트워크 구조에 관심. 전기 시스템과 소프트웨어, 네트워크 기술이 실제 환경에서 어떻게 연결되는지 학습 중.

웹 서비스와 네트워크

컴퓨터네트워크의 여러 주제 중 이 페이지는 웹 서비스 동작 과정에 초점을 둔 구성. 사용자가 웹사이트에 접속할 때 도메인, DNS, IP 주소, HTTP, 웹서버가 함께 사용된다.

웹사이트 접속 과정

사용자가 브라우저에 주소를 입력하면, 브라우저는 해당 도메인이 어떤 네트워크 주소와 연결되는지 확인한다. DNS는 도메인 이름에 대응되는 IP 주소 정보를 찾아주고, 브라우저는 그 주소를 이용해 웹서버에 요청을 보낸다. 웹서버는 HTML, CSS, JavaScript 같은 웹페이지 데이터를 응답하고, 브라우저는 이를 해석해 화면에 표시한다.

HTML

웹페이지의 제목, 문단, 메뉴, 카드, 섹션 같은 기본 구조를 만드는 언어.

CSS

웹페이지의 색상, 배치, 크기, 반응형 화면, 시각적 디자인을 담당하는 언어.

HTTP / HTTPS

브라우저와 웹서버가 웹페이지 데이터를 주고받기 위해 사용하는 통신 방식.

Domain

사용자가 기억하기 쉬운 웹사이트 주소. 실제 접속 과정에서는 IP 주소와 연결되어 사용된다.

Web Server

브라우저의 요청에 따라 웹페이지 데이터를 제공하는 서버.

GitHub Pages

HTML, CSS, JavaScript로 구성된 정적 웹페이지를 인터넷에 공개할 수 있는 호스팅 서비스.

컴퓨터네트워크 속 DNS 파트

DNS는 사람이 기억하기 쉬운 도메인 이름을 실제 접속에 필요한 IP 주소 정보로 찾아주는 시스템. 사용자는 복잡한 숫자 주소 대신 도메인 이름으로 웹사이트에 접속할 수 있다.

Client 브라우저에서 도메인 주소 입력
→
DNS 도메인 이름에 대응되는 IP 주소 확인
→
Web Server 웹페이지 데이터 응답

A Record

도메인 이름을 IPv4 주소와 연결하는 DNS 레코드.

CNAME Record

하나의 도메인 이름을 다른 도메인 이름으로 연결하는 DNS 레코드.

TTL

DNS 정보가 일정 시간 동안 저장될 수 있는 기준 시간.

이 파트에서 보는 핵심

DNS 파트의 핵심은 도메인 이름과 IP 주소 정보가 어떻게 연결되는지 이해하는 것. 웹사이트 접속은 도메인 입력, DNS 조회, 웹서버 요청, 웹페이지 응답이 이어지는 흐름으로 볼 수 있다.

전기공학 소개

전기공학은 전기에너지의 발생, 전달, 변환, 제어, 활용을 다루는 분야. 회로, 제어, 전력, 전자, 임베디드 시스템 등 다양한 기술과 연결.

회로 이론

전압, 전류, 저항, 전력의 관계와 회로 해석.

제어공학

시스템의 입력과 출력을 원하는 방향으로 조절하는 원리.

전력 시스템

발전, 송전, 배전, 부하로 이어지는 전기에너지 흐름.

전자회로

반도체 소자와 회로 구성을 통한 신호 처리.

임베디드 시스템

센서, 보드, 코드 기반의 실제 동작 시스템.

융합 기술

전기공학과 소프트웨어, 네트워크 기술의 결합.

정리
